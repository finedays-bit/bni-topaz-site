# BNI 토파즈 챕터 사이트

BNI 토파즈 챕터(동탄) 공식 사이트. 담당자가 바뀌어도 관리자 페이지에서 멤버·명함·주간 초대장을 바로 고칠 수 있게 만든다.

- 예정 주소: `bnitopazchapter.site` (철자 확정 전)
- 기존 사이트: https://topaz.bnichapter.site/ (교체 대상)

## 화면

| 경로 | 내용 |
|---|---|
| `/` | 챕터 소개 · 모임 시간·장소 · 실적 숫자 · 참관 신청 버튼 |
| `/members` | 이미지 명함 목록 (파워팀별 필터) |
| `/invite` | **고정 주소 주간 초대장** — 관리자가 입력한 이번 주 정보로 웹 초대장과 초대장 이미지(PNG)가 자동 갱신, 아래에 참관 신청서 |
| `/admin` | 멤버 추가·탈퇴, 명함 이미지 교체, 이번 주 초대장 입력, 참관 신청자 확인, 관리자 메일 초대(인수인계), **디렉터·앰배서더 명함 만들기**(담당 교체 시 이름·직함·회사·문구·연락처 입력 + 누끼·로고 업로드 → 토파즈 틀 PNG 자동 생성. 규칙은 `scripts/director-cards/만들기.py`) |

## 기술

Next.js + Supabase(DB·로그인·초대 메일·이미지 저장) + Vercel(배포)

## 진행 단계

1. 화면 초안 (메인·멤버·초대장, 샘플 데이터)
2. 관리자 페이지 + Supabase 연결 + 메일 초대
3. 초대장 이미지 자동 생성 + 참관 신청서
4. 배포 + 도메인 연결
